# Java Day 2 - Variables and Data Types

This is my second Java program.

In this program, I learned how to create variables and store different types of data in Java.

## Example

The program stores:

* Name using `String`
* Age using `int`
* Marks using `double`

## Output

```text
Name: Suyash
Age: 21
Marks: 78.5
```

## Concepts Used

* Variables
* `String`
* `int`
* `double`
* `System.out.println()`
* String concatenation using `+`

## How It Works

1. Create a `String` variable to store a name.
2. Create an `int` variable to store age.
3. Create a `double` variable to store decimal marks.
4. Use `System.out.println()` to display the values.
5. Use `+` to combine text with variables.

## Java Code

```java
public class Main
{
    public static void main(String[] args)
    {
        String name = "Suyash";
        int age = 21;
        double marks = 78.5;

        System.out.println("Name: " + name);
        System.out.println("Age: " + age);
        System.out.println("Marks: " + marks);
    }
}
```

## Output

```text
Name: Suyash
Age: 21
Marks: 78.5
```

## Goal

The goal of this project is to understand basic variables and data types in Java.
